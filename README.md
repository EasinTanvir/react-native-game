## 📱 Navigation & Modal Configuration

### 🔙 Back Button (Minimal Style)

Remove the default back button title for a cleaner UI:

headerBackButtonDisplayMode: "minimal"

---

### 🪟 Modal Presentation

Default modal:
presentation: "modal"

Recommended (better UI):
presentation: "formSheet"

---

### ⚙️ Form Sheet Customization

sheetAllowedDetents: [0.3, 0.5, 0.7]
sheetGrabberVisible: true

---
